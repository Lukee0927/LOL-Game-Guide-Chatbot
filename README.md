# LOL-Game-Guide-Chatbot
A web development project featuring a League of Legends chatbot guide system that provides beginner tips, game suggestions, and interactive assistance. Built using HTML, CSS, JavaScript, PHP, and MySQL with an admin panel for managing chatbot responses.

The League of Legends Chatbot Game Guide System is a web-based platform designed to assist beginner players in learning and improving their gameplay experience through an interactive chatbot. The system provides accessible game guides, tips, and recommendations related to League of Legends, helping users understand game mechanics, strategies, and common beginner concerns.

The website includes a homepage that allows users to navigate between the chatbot and guide sections. The chatbot functions as a virtual game assistant that provides answers to beginner questions, gameplay suggestions, and helpful recommendations using predefined scripts. An administrator panel is also included, allowing authorized users to create, update, and delete chatbot scripts to maintain and improve the accuracy of the chatbot's responses.

The system was developed using HTML, CSS, JavaScript, and PHP, with MySQL used for database management. HTML and CSS were utilized for structuring and designing the user interface, JavaScript was used to enhance interactivity and user experience, PHP handled the backend logic and communication between the system components, and MySQL stored chatbot scripts, guides, and related data.

Overall, the platform serves as a beginner-friendly learning companion for League of Legends players by combining interactive chatbot assistance, organized game resources, and an easy-to-manage content system.
